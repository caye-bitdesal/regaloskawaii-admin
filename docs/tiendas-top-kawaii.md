# Tiendas para el «Top kawaii» semanal

La tarea programada «Top kawaii semanal» lee esta lista cada lunes desde GitHub (rama main), así que los cambios cuentan en cuanto haces push. Para añadir una tienda, añade una línea en «Lista» con el formato:

`- Nombre de la tienda | URL de búsqueda o de más vendidos (opcional) | notas (opcional)`

Amazon no va aquí: sus productos se dan de alta a mano hasta tener acceso a la Creators API.
